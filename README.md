# Counter Project

A simple counter application built using **HTML, CSS, and JavaScript DOM manipulation**.

## Features

- **Increment:** Increase the count by 1.
- **Decrement:** Decrease the count by 1.
- **Clear:** Reset the count to 0.
- **Error Message:** Display an error message when attempting to decrease the count below 0.
- **Dynamic Clear Button:** Hide the Clear button when the count is 0.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
Counter-Project/

```

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Use the Increment, Decrement, and Clear buttons to operate the counter.

## Learning Objectives

- Understand JavaScript DOM manipulation.
- Handle button click events.
- Update HTML elements dynamically.
- Use conditional statements to handle errors.
